# مشروع AwsanBot - Phone-to-n8n-LiveKit Ecosystem

## الأهداف الرئيسية
- **نظام إدارة عيادات أطباء وأسنان متكامل**: يوفر وكيلاً ذكياً تفاعلياً (Voice AI Agent) للرد على المكالمات الهاتفية المباشرة واستفسارات العملاء وحجز المواعيد وتحديثها تلقائياً.
- **بيئة Phone-to-n8n-LiveKit**: ربط الاتصالات الصوتية منخفضة التأخير عبر خادم LiveKit مع محرك الأتمتة n8n والذكاء الاصطناعي (OpenAI).

## نطاق العمل والتكاملات
- **البنية الصوتية**: LiveKit Server + LiveKit Agents (Python) باللغة العربية.
- **محرك الأتمتة**: n8n للربط عبر Webhooks وسير العمل ذاتي الاستضافة.
- **التكاملات البرمجية السحابية**: Google Calendar (المواعيد), Google Sheets (البيانات), Google Contacts (بيانات المرضى والعملاء).
- **القنوات المستهدفة**: اتصالات SIP/الهاتف المباشرة، محادثات الصوت، والتكامل المستقبلي مع واتساب وتليجرام.
