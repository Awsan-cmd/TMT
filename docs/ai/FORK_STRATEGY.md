# استراتيجية التكييف وإدارة المكونات (Fork & Customization Strategy)

## استراتيجية التوافق واستقلالية المكونات
1. **استقلالية مكونات البنية التحتية**: تشغيل LiveKit و n8n في حاويات Docker منفصلة ومحايدة لضمان ترقيتها بسهولة.
2. **فصل منطق الوكيل (Decoupled Agent Logic)**: `agent.py` يعتمد على الواجهات القياسية لـ `livekit-agents`.
3. **التكيف مع التحديثات**: الاحتفاظ بالتخصيصات والـ Webhooks داخل سير عمل n8n وملف `agent.py` دون التعديل المباشر على الصور الأساسية.
