# القرارات المعمارية (Architectural Decisions)

## ADR-001: اعتماد LiveKit و n8n للبنية الصوتية والأتمتة
- **التاريخ**: 2026-08-28
- **القرار**: استخدام LiveKit لمعالجة الصوت المباشر و n8n للربط مع Google APIs.
- **السبب**: تقليل زمن التأخير (Latency) لضمان محادثة صوتية سلسة، وتوفير بيئة أتمتة مفتوحة المصدر ومستضافة ذاتياً.
- **الحالة**: APPROVED
