# سجل القرارات التقنية والمعمارية (Architectural Decision Records)

## ADR-001: اعتماد LiveKit و n8n للبنية الصوتية والأتمتة
- **التاريخ**: 2026-08-28
- **القرار**: استخدام LiveKit لمعالجة الصوت المباشر المنخفض التأخير و n8n لأتمتة العمليات والربط مع Google APIs.
- **السبب**: تقليل زمن الاستجابة (Latency) وتوفير بيئة مرنة مفتوحة المصدر ومستضافة ذاتياً.
- **الحالة**: APPROVED

## ADR-002: اعتماد Python LiveKit Agents وتكامل Webhooks المباشر
- **التاريخ**: 2026-08-28
- **القرار**: كتابة الوكيل الصوتي `agent.py` باستخدام `livekit-agents` مع دعم اللغة العربية واستخدام HTTP Webhooks للاتصال بـ n8n على المنفذ `5678`.
- **السبب**: فصل منطق المعالجة الصوتية والتفاعلية عن منطق العمليات التجارية (Business Logic) المدار بواسطة n8n.
- **الحالة**: APPROVED

## ADR-003: اعتماد بوابة أندرويد (Android Gateway) للهواتف القديمة (Galaxy S5 - API 23)
- **التاريخ**: 2026-08-28
- **القرار**: بناء تطبيق أندرويد مخصص باسم `android-gateway` يستهدف Android 6.0 (API Level 23) لالتقاط المكالمات الواردة وتكشيف بروتوكول الاتصال مع n8n و LiveKit.
- **السبب**: الاستفادة من الهواتف الذكية المتاحة (مثل Samsung Galaxy S5) كبوابة اتصال هاتفية (GSM Gateway) منخفضة التكلفة دون الحاجة لبنية SIP معقدة في المراحل الأولى.
- **الحالة**: APPROVED
