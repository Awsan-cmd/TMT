# قواعد إدارة الذاكرة الدائمة (Memory Rules)

1. **مصدر الحقيقة**: ملفات `docs/ai/` و `AGENTS.md` هي المرجع الأساسي الحاكم لقرارات المشروع والكود.
2. **التحديث التلقائي**: يجب تحديث ملفات `CURRENT_STATE.md`, `FEATURES.md`, و `CHANGELOG.md` مع كل مهمة ناجحة.
3. **عدم النسيان**: أي قرار أو هيكل جديد يجب توثيقه فوراً في المكان المخصص له ولا يعتمد على المحادثة المؤقتة.
